# 🚀 Featured Projects

## 🚗 [CrashInterpreter — RAG-Augmented Crash Narrative Interpreter](https://github.com/HamidrezaAmin/CrashInterpreter)

An AI-assisted transportation safety system that interprets police crash narratives and predicts structured crash-report classifications.

The system combines **Retrieval-Augmented Generation (RAG)** with official transportation coding guidance to help automate the interpretation of complex crash narratives.

### Key Components
- Retrieves relevant coding rules using **FAISS vector search**
- Uses an LLM to interpret crash narratives
- Produces structured JSON predictions
- Validates model outputs with **Pydantic**
- Includes a **Streamlit** interface for single and batch processing
- Supports automated integration with structured crash datasets

### Tech
`Python` · `LLMs` · `RAG` · `OpenAI API` · `FAISS` · `Pydantic` · `Streamlit`

### Evaluation
Achieved approximately **87.9% overall classification accuracy** across evaluated crash-report fields in the initial test set.

## 🛣️ [MobileCentury-TSE — Traffic State Estimation from Sparse Probe Vehicles](https://github.com/HamidrezaAmin/MobileCentury-TSE)

A transportation data science project investigating how accurately highway traffic conditions can be reconstructed using a limited number of GPS-equipped probe vehicles.

Using the **Mobile Century** traffic dataset, the project reconstructs highway speed fields and evaluates them against independent traffic sensors.

### Research Questions
- How much probe-vehicle penetration is needed for reliable traffic estimation?
- How does reconstruction accuracy change under congested vs. free-flow conditions?
- Can sparse mobile GPS observations reproduce network-level traffic states?
- How should traffic-state estimates be validated against independent sensors?

### Methods
- Space-time traffic data aggregation
- Adaptive smoothing
- Probe-vehicle sampling experiments
- Loop-detector validation
- Traffic-state reconstruction
- Statistical error analysis

### Tech
`Python` · `Transportation Data` · `Traffic Analytics` · `NumPy` · `Pandas` · `Scientific Computing`

## 🏢 [T3C — Temporal Transformer for Thermal Comfort](https://github.com/HamidrezaAmin/T3C-Thermal-Comfort-Transformer)

A deep-learning project applying **Transformer architectures** to thermal-comfort prediction for smart-building applications.

The project explores temporal modeling of environmental conditions and occupant comfort using the ASHRAE Global Thermal Comfort Database II.

### Key Components
- Transformer encoder architecture
- Physics-informed synthetic temporal sequence generation
- Environmental change-rate features
- Participant-independent model evaluation
